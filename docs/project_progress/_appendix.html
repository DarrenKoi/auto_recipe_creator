02

PoC 핵심 방향 — VLM과 CV의 역할 분리

화면 의미 이해는 VLM에, 정밀 좌표·정량 점수는 CV에 맡겨 무인 자동화의 신뢰도를 확보합니다. (설계 원칙 확정: 2026-05-25)

Perception

VLM — "어디를 볼까"
  • UI 요소 위치, Align Key 후보 영역 식별
  • OM / SEM 촬영 모드 판독
  • 모호한 화면 설명, 보정 가능성 판단
  • 강점: 화면 의미 이해 · 한계: 이전 화면 기억 못함 · 픽셀 정확도
vs

Decision

CV — "정확히 어디 · 얼마나 닮았나"
  • 이미지 매칭 정량 점수 산출
  • 최종 클릭 좌표 결정
  • 반복 가능 · 정량적
  • VLM이 못 하는 "기억"을 데이터로 대신
원칙 — 낮은 CV 점수를 VLM 답변이 덮어쓰지 않으며, 반복 가능한 단계 전환을 VLM이 결정하지 않습니다. 좌표·점수의 최종 권한은 항상 CV에 있습니다.
