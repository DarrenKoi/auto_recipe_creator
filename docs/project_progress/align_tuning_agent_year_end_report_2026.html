3. 올해 만든 것

VLM 인프라

운영 중
  • 오픈소스 소형 모델 5종(VLM 3 + OCR 2)을 사내 HCP 에 배포 · 평가했습니다.
  • 업무 화면 벤치로 비교해 이긴 2종만 상시 운영합니다. 모델 교체는 측정으로 결정합니다.

GUI 자동화

실장비 확인
  • 단일 모델은 클릭이 매번 어긋났습니다. 영역 → 정밀 좌표 → OCR 확인으로 바꿔 99% 를 얻었습니다.
  • 접속 전 List 의 Connection User 를 읽어, 엔지니어가 쓰는 장비에는 들어가지 않습니다.

정렬 정확도 (CV 벤치)

반영 완료
  • Recipe 200개 오프라인 벤치에서 아이디어를 A/B 하고, 이긴 것만 실시간 루프로 옮겼습니다.
  • 남은 오답의 약 87% 는 구분이 어려운 위치에 등록된 Align Key 라, 재등록 대상 목록을 자동으로 뽑습니다.

실시간 대응 루프

완전 자동
  • Align Key 가 화면에 없으면 배율을 낮춰 격자로 찾는 Search Around 를 넣었습니다.
  • OK 뒤 다음 측정 위치의 Align Fail 도 이어서 보정하고, 결과 알림은 Cube 로 반드시 전달합니다.

6. 기대 효과

주 약 27시간 장비 시간 회수 = Wafer 약 100장/주 추가 측정
  • 건당 4분 × 주 400건 기준이며, 장비 약 0.2대(Capex 약 4~5억 원)에 해당합니다. 배치 후 실측값으로 갱신합니다.
  • 야간 · 주말에도 대응하고, 실패 화면과 녹화가 남아 원인 분석과 다음 개선 순서를 데이터로 정합니다.
  • VLM 이 화면을 직접 읽어 버튼 좌표나 이미지를 저장해 둘 필요가 없어, 다른 장비군에도 프롬프트와 기준 이미지만 바꿔 적용할 수 있습니다.

8. 이후 과제

Headless 장비 제어

진행 중

지금의 GUI 기반 자동화는 Agent 가 RCS 화면을 보고 마우스 · 키보드를 직접 움직이므로, 가동 중에는 Agent 가 컴퓨터를 점유합니다. 현재 reverse engineering 으로 RCS 화면을 거치지 않고(headless) 장비를 제어할 수 있는지 테스트하고 있습니다.

Agent 가동 중에도 엔지니어는 같은 PC 에서 다른 작업을 병행할 수 있습니다
  • AI 전용 RCS 계정 발행 · IP 방화벽 해제는 끝났습니다. 상시 운영 PC 를 마무리하고 단일 장비 pilot 후 R3 26대로 확대합니다.
  • Search Around 와 다음 위치 추적을 실알람에서 검증하고, 대응 결과를 건별로 쌓아 실측 성공률을 냅니다.
  • 재등록 대상 Recipe 를 현업과 대조해 더 뚜렷한 위치로 Align Key 재등록을 추진합니다.
  • 2027년에는 이 구조를 발판으로 VLM 이 Recipe Tuning 을 직접 수행하도록 확장합니다.
