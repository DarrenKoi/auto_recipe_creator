# Align Fail 대응 지능화 Agent — 1장 보고 + 발표 스크립트

> 대상: 임원 보고 / 분량: 슬라이드 1장 + 발표 2분(약 780자, 분당 350~380자 기준)
> 시연 영상 설명은 이 원고에 포함하지 않습니다(별도 진행).

## 슬라이드 1장 (4블록)

### ① 배경 — 고질적 Align Fail

- R3 CD-SEM 전체 측정의 **5%**가 Align Fail, **주 평균 400건**
- 원인: 연구소 특성상 Lot Split·공정 Variation → Recipe 등록 Align Key ↔ 실제 Wafer 이미지 차이
- 현재: 인라인 여사원·현업 엔지니어 수동 대응, **건당 5분**
- 룰 기반 자동화 불가: 동일 모델도 장비마다 UI 구조가 다름 (비표준 버튼·창)

### ② 추진 전략 — 3단계

| 단계 | 내용 |
|---|---|
| 전용 모델 확보 | 사내 LLM 한계 → 오픈웨이트 모델 다수 평가 후 본 업무 최적 모델 선정 |
| GUI 자동화 | 선정 모델로 **RCS + 장비 GUI** Agent 조작 완성 |
| 좌표는 CV가 | 재정렬 위치는 LLM이 아닌 전통 Computer Vision이 결정 |

- 오프라인 벤치(Recipe 200개): **OM 80% 후반 / SEM 60~70%**

### ③ Agent–엔지니어 협업 + 학습 루프

- Agent 처리 불가(이미지 흐림·잘못된 Recipe) → **즉시 Cube 알람**(Recipe 정보 동봉)
- 엔지니어 마무리 작업 **자동 녹화** → 의미 있는 조작만 추출 → **Workflow 자산화**
- 향후 Auto Recipe Creation Agent 개발의 노하우·암묵지 기반

### ④ 기대 효과

- 건당 대응 **5분 → 1분 이내** (4분 회수)
- Wafer당 20분 측정 기준 **주 100장 추가 측정**
- 장비 가동률 환산 **일 0.2대** ≒ CG6300(대당 20억) 기준 **Capex 약 4억**

## 발표 스크립트 (2분)

**[도입 · 배경 — 약 40초]**

안녕하세요, AX Part 최대영 TL입니다. Align Fail 대응 지능화 Agent 진행 사항 보고드리겠습니다.

R3 CD-SEM은 전체 측정의 5%, 주 평균 400건이 Align Fail입니다. 연구소 업무 특성상 Lot Split과
공정 Variation이 많다 보니 Recipe에 등록된 Align Key 이미지와 실제 Wafer 이미지가 어긋나기
때문입니다. 지금은 인라인 여사원과 현업 엔지니어가 건당 5분씩 수동으로 대응하고 있습니다. 룰
기반 자동화는 같은 모델이라도 장비마다 UI 구조가 달라 적용이 어려웠습니다. 그래서 사람이 24시간
지키던 이 업무를 AI Agent가 대신하는 것을 목표로 잡았습니다.

**[추진 전략 — 약 45초]**

전략은 세 가지입니다. 첫째, 사내 제공 LLM으로는 이런 특화 업무에 한계가 있어 오픈웨이트 모델
여러 종을 직접 테스트해 최적 모델을 선정했습니다. 둘째, 그 모델로 Fab 장비 접속 경로인 RCS와
장비 GUI를 Agent가 직접 조작하도록 자동화를 완성했습니다. 셋째, 재정렬 위치는 LLM이 관여할 수
없는 영역이라 전통적인 Computer Vision으로 찾도록 했습니다. Recipe 200개 오프라인 벤치에서 OM
이미지는 80% 후반, SEM 이미지는 60~70% 성공률을 확보했습니다.

**[협업·학습 루프 — 약 20초]**

Agent가 직접 처리하지 못하는 경우에는 즉시 Cube로 엔지니어를 호출하고 엔지니어가 마무리하는
작업을 그대로 녹화합니다. 여기서 의미 있는 조작만 추출해 Workflow로 저장하면 Agent의 학습
루프가 되고 향후 Auto Recipe Creation Agent 개발에 쓸 암묵지 자산이 됩니다.

**[기대 효과 — 약 15초]**

기대 효과는 건당 5분을 1분 이내로 줄이는 것입니다. 회수되는 4분은 Wafer당 20분 측정 기준으로
주 약 100장 추가 측정, 장비 가동률로는 하루 0.2대, CG6300 대당 20억 기준 Capex 약 4억 규모입니다.
