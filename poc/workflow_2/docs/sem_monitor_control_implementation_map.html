Workflow 2 SEM Monitor 제어 구현 맵

Align Fail 이후 RCS의 오른쪽 아래 SEM Monitor를 1~2초 주기로 관찰하고, Align Key 위치를 찾을 때까지 더블클릭 이동과 마우스 휠 배율 조정을 반복하는 자동화 흐름을 현재 구현 상태와 남은 작업으로 분리했다.

작성일 2026-05-23 범위: poc/workflow_2
결론

구현은 가능하다. 다만 VLM이 최종 Align Key 좌표를 직접 결정하는 구조가 아니라, deterministic CV matcher가 좌표와 score를 결정하고 VLM은 SEM Monitor 영역 식별, 애매한 후보 설명, 다음 탐색 방향 보조에 제한해서 사용하는 구조가 맞다.

Primary Decision

match 여부는 Chamfer + ORB score가 결정한다.

Actuation

SEM Monitor 이동은 ROI 내부 screen 좌표로 변환한 뒤 더블클릭으로 수행한다.

Magnification

휠 up/down은 low 또는 partial match 상태에서만 bounded policy로 사용한다.

실행 흐름

Observe
SEM Monitor 캡처
Remote Monitoring System 전체 창에서 SEM Monitor ROI만 잘라 live FOV로 사용한다.
Score
Align Key 매칭
recipe template과 live FOV를 compute_align_key_score()로 비교한다.
Decide
match / adjust / low
score가 높으면 종료, 애매하면 보정, 낮으면 search pattern과 zoom policy로 이동한다.
Act
더블클릭 이동 / 휠 배율
SEM Monitor 내부 좌표를 screen 좌표로 환산해 더블클릭하고, 필요 시 wheel을 사용한다.
Verify
재캡처 및 종료 판정
1~2초 settle 후 다시 캡처해 score가 개선되는지 확인하고 debug artifact를 남긴다.

우리가 구현한 것

구현됨

Classical CV matcher

align_key_matcher.py가 CLAHE, Canny, Chamfer, ORB/RANSAC, 합성 score와 debug overlay 생성을 담당한다.

구현됨

Search loop shell

search_align_key.py가 capture_fn, move_stage_fn, vlm_consult_fn 주입 구조를 제공한다.

검증됨

Synthetic validation

합성 box Align Key positive/negative 10개 케이스가 통과했고, search demo도 목표 좌표를 0 px 오차로 찾았다.

구현됨

Frame 변화 필터링

filter_frames_by_change.py가 정적 프레임을 제외해 VLM/CV 처리량을 줄인다.

부분 구현

SEM Monitor Box 탐지

vlm_sem_monitor_box.py와 sem_panel_locator.py가 SEM Monitor ROI 탐지 방향을 제공한다. 실제 landmark assets는 추가가 필요하다.

부분 구현

Cursor / click 분석

vlm_cursor_click_filter.py가 커서 위치와 변화 영역을 결합해 click event를 분류한다.

재사용 가능

Window / mouse utilities

기존 capture_window(), click_at_screen(), scroll_at_screen()으로 캡처, 더블클릭, wheel 제어를 수행할 수 있다.

앞으로 해야 할 것

구현 항목 필요 이유 완료 기준 우선순위
Live SEM capture adapter 현재 search loop는 capture_fn 주입점만 있고 실제 RCS SEM Monitor 캡처 함수가 없다. 1~2초 주기로 SEM Monitor ROI를 numpy frame으로 반환하고, ROI overlay JPEG를 저장한다. 최우선
Double-click move adapter SEM Monitor 내부 좌표와 screen 좌표 변환, 이동 방향 부호 검증이 필요하다. move_stage_fn(state, dx, dy)가 SEM Monitor 내부 target point를 더블클릭하고 새 state를 반환한다. 최우선
Magnification wheel policy Align Key가 너무 작거나 큰 경우 wheel up/down으로 배율을 조정해야 한다. low 연속, partial match, best_scale 이탈 상황별 wheel action과 max retry가 정의된다. 높음
Recipe template 공급 현재 실제 recipe align key template과 nm_per_pixel metadata가 없다. recipe_id/version/template image를 받아 AlignKeyTemplate으로 build하고 cache/version을 기록한다. 최우선
Real-data calibration 현재 threshold는 cold-start 값이고 synthetic test는 production accuracy를 보장하지 않는다. positive/negative/hard-negative 실 SEM 샘플로 score distribution과 threshold를 산출한다. 높음
Safety gate 실장비 제어는 오동작 시 영향이 크므로 기본 dry-run과 클릭 범위 제한이 필요하다. SAFE_MODE=true 기본값, ROI 밖 클릭 차단, max move/zoom 제한, emergency stop이 동작한다. 최우선
Engineer escalation low가 반복되면 자동으로 계속 움직이지 말고 사람이 판단할 자료를 보내야 한다. 최근 5회 score, recipe template, best SEM frame, edge overlay를 3-pane image로 저장한다. 중간

실장비 통합 순서

Phase 1
Dry-run capture loop
RCS 창을 활성화하고 SEM Monitor ROI를 1~2초 주기로 캡처한다. 이 단계에서는 클릭하지 않는다.
Phase 2
Offline matcher calibration
실제 recipe template과 live FOV를 모아 Chamfer/ORB score 분포를 확인한다.
Phase 3
Move adapter dry-run
계산된 double-click 좌표와 wheel action을 로그/overlay로만 검증한다.
Phase 4
Bounded live action
1회 이동량, zoom 횟수, low streak limit을 제한한 상태에서 실장비 동작을 켠다.

VLM 사용 경계

사용해도 되는 영역 피해야 할 영역
SEM Monitor Box 식별 최종 Align Key 좌표 단독 결정
feature 없는 FOV인지 설명 VLM confidence를 calibrated score처럼 사용
adjust 구간의 coarse direction hint OpenCV low score를 VLM 답변만으로 override
engineer review summary 생성 반복 가능성이 필요한 stage movement 판정
운영 원칙 픽셀 수준의 정량 score는 OpenCV가 만들고, VLM은 화면 이해와 애매한 상황 설명에 사용한다.
