② 진행 상황

#단계상태설명
1SEM 화면 영역 검출✅ 완료모든 탐색의 기준점인 live SEM 박스를 검출, 장비별 기준 위치 저장
2OK 버튼 검출·클릭✅ 완료보정을 확정하는 마지막 동작, OCR 재확인으로 오클릭 차단
3흰 박스 제거 (template)✅ 완료고정 디지털값(히스토그램 섬) photometric 검출로 박스 안쪽만 crop, 최악 샘플 1/6→6/6 (합성검증)
4십자(crosshair) 제거 (frame)✅ 완료십자 검출→위치를 정답으로 기록→inpaint, 재검출+edge밀도로 제거 이중 검증 (합성검증)
5Align Point 정확도 검증📍🔄 진행 중2×2 비교(박스·십자 정리 효과 분리) + S전용 위치추정 검증(1발 명중률), 오피스 데이터 대기
6실장비 FOV Search Loop⏳ 대기검증 통과 후 실 SEM 연결 어댑터·안전장치 구현 → 매처 결과로 stage 이동
