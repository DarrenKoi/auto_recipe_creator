이번 주는 Workflow 1(RCS 자동화)의 클릭 파이프라인을 실장비 수준으로 견고화하고, Workflow 2(Align Key 보정)에서 "즉시 보정(PRIMARY)" 경로와 SEM Box 검출 코어의 단일 소스화를 완성했습니다. 핵심 설계 원칙 — 좌표는 CV가 결정하고 VLM은 영역 식별에만 쓴다 — 이 OK 버튼 grounding과 box snap 양쪽에서 일관되게 적용되었습니다.

② Workflow 1 — RCS 자동화

RCS 로그인 → Tool 선택 → Align Fail 감지 → Tool 화면 캡처
항목상태설명
클릭 파이프라인 재설계 완료 coarse(ui-venus)→fine(mai-ui)→confirm(OCR) 구조로 전환. OCR은 확인 전용, 미확인 시 클릭 금지. tool-click 경로에서 PaddleOCR 제거하고 VLM 합의(ui-venus↔mai-ui)를 신뢰.
Windows DPI 배율 보정 완료 패키지 import 시 Per-Monitor DPI aware 설정. image→screen 좌표를 rect/screenshot 비율로 보정해 125/150% 배율 환경의 클릭 빗나감 해결.
Spotting 기반 tool 검출 완료 List 탭에서 tool ID를 VLM Spotting으로 우선 검출 후 더블클릭. 신호등(녹/검) 컬럼 기준 왼쪽 집중 crop.
align_fail_alarm_record.py 완료 알람당 open→record→close 전체 사이클. 알람 캡처 전 alert 팝업 먼저 닫기, RCS 점유 시 tool 창 탐색 10회 상한, 기록 중 PC awake 유지.
workflow_close_tool.py 완료 title의 tool id로 열린 Tool(Remote Monitoring System) 창을 안전하게 닫음.
타임존/매니페스트 정합 완료 record-manifest의 alarm_time을 UTC+9로 통일해 캡처 폴더 태그와 일치. 알람 이력 CSV 누적.

③ Workflow 2 — Align Key 보정

Align Fail Tool의 SEM Monitor를 조작해 레시피 등록 align key와 같은 위치 찾기
항목상태설명
PRIMARY 보정 (align_fail_correct.py) Mac 검증 paused 프레임을 등록 배율(near-native)로 매칭 → key_visibility_gate로 가시성 판정 → best 좌표 더블클릭 recenter → VLM으로 OK 버튼 찾아 screen 클릭. dry-run 기본, self-test 4/4(gate/primary/fallback/OK 매핑). 실장비·VLM은 오피스 전용.
OK 버튼 grounding Mac 검증 vlm_ok_button_box.py / vlm_wait_input_ok_button.py: paused 다이얼로그의 OK를 VLM으로 식별해 screen 좌표 반환. Spotting + popup 텍스트 위치 기반 공간 게이트로 오클릭 차단. reposition(FOV-local)과 OK(screen 절대) 좌표공간 분리.
SEM Box 검출 코어 (sem_box_detect.py) Mac 검증 VLM coarse(영역) → CV 회색-프레임 끊김 없는 긴 직선 run으로 snap(약하면 Sobel 폴백) → 내부 Laplacian sharpness. offline/online이 같은 함수 사용 → 임계값 단일 튜닝.
offline 드라이버 + 장비별 reference Mac 검증 outline_live_sem_box.py: overlay/greymask JPEG로 눈 검증, 여러 캡처 중앙값으로 robust한 sem_box_references/<eqp_id>.json(0–1000 정규화 + spread) 생성. production에서 box moved/closed 감지 기반.
실시간 SEM box 식별 진행 vlm_sem_monitor_box_realtime.py: live 프레임에서 SEM Monitor Box 영역 식별(좌표 결정 아님).
설계 문서 · ADR 완료 ADR 0001(current-sem은 다운로드 아닌 live 캡처), 0002(PRIMARY reposition vs FALLBACK 탐색). SEM box 데이터 흐름/입문 explainer, 오프라인 실험 runbook 작성.
완료 구현·검증 완료 Mac 검증 로직·합성 검증 완료, 실장비/VLM은 오피스 전용 진행 작업 중
