# 접속 전 List 점유 게이트

> CLAUDE.md 에서 옮겨 온 원문(2026-09-19). 이 기능을 고치기 전에 끝까지 읽을 것 - 계약은 오피스 실측에서 나왔고 Mac 에서 재현할 수 없다.

**접속 전 List 점유 게이트** (2026-09-15 오피스 확인, `poc/workflow_3/check_tool_occupancy.py`): tool 더블클릭 **전에** List 탭의 같은 행을 읽어 `free` 일 때만 접속한다. `cycle._exec_connect_tool` 이 `connect_to_tool(require_occupancy_check=True)` 로 항상 켜며(`manual_align_correction.py` 는 2026-09-17 부터 엔지니어가 **직접 연 tool 창에 붙으므로** `run_alarm_cycle(attach_open_tool=True)` 로 RCS 확보/List 접속 step 을 빼고 이 게이트도 거치지 않는다 - 점유는 `free` 로 둔다), `occupied_by_other`→`rcs_occupied`, `unknown`→`rcs_occupancy_unknown` 으로 접속을 보류하고 둘 다 `_OCCUPIED_FAILURE_CLASSES` 라 **cooldown 재시도**다(판독 실패는 우리 인식 실패라 active 로 굳히면 영영 재시도 안 됨). 단독 점검은 파일 상단 `ACTION_TARGET_TOOL_NAME` 고치고 `uv run python -m poc.workflow_3.check_tool_occupancy`(클릭 없음, `TOOL_OCCUPANCY_IMAGE` 로 저장 이미지도 가능). **오피스 실측 5회가 만든 계약 — 모두 "VLM 은 좌표, PaddleOCR 은 판독" 규칙 위반에서 나온 실패다**: ① **행 위치는 클릭 경로의 `_locate_tool_via_vlm` 를 그대로 쓴다**(List 전체 + tool-list result mode + 행 확인 게이트). MC ID 컬럼만 잘라 넣으면 좁고 긴 strip 의 행이 전부 같아 보여 mai-ui 가 이웃 행을 고른다. ② **로케이트는 요소당 호출 하나**. 헤더 여러 개를 한 JSON 으로 나열시키면 하나만 빠져도 이웃 경계가 전부 밀리고, 컬럼 **폭**을 물으면 mai-ui 는 점은 잘 찍지만 폭은 어림한다(MC ID 2배/Remote 1/2/Connection User 왼쪽 잘림). 그래서 MC ID 컬럼은 행 점 좌우 `MC_ID_HALF_WIDTH_PX`(60) 고정 pad, Connection User 는 그 헤더 **하나**를 `analyze_window_target` 로 찾아 bbox 왼쪽 - `CONNECTION_USER_LEFT_PAD_PX`(40) 부터 **이미지 오른쪽 끝까지**(마지막 컬럼). 좌표를 물을 땐 0-1000 이 mai-ui 의 native 라 절대 px 를 요구하면 오른쪽 컬럼이 절반 x 로 온다. ③ **Remote 컬럼은 보지 않는다** — 헤더 경계가 검증에서 자꾸 떨어졌고 Connection User 만으로 충분하다(사용자 결정). ④ **셀 판독은 PaddleOCR**(`read_text_near_point`, MC ID 확인과 같은 경로) — VLM 전사는 빈 셀에서 환각해 빈 tool 을 점유로 읽었다. PaddleOCR 도 빈 crop 엔 `[Table_Page_Number]` 같은 대괄호 레이아웃 태그를 내므로 "글자가 있으면 점유" 는 틀리고, **대괄호 토큰을 버린 뒤 첫 단어가 `Control` 로 시작할 때만 점유**(`OCCUPIED_PREFIX`; 점유 셀은 `Control <user>` 로 읽힌다)다. ⑤ **PaddleOCR 이 MC ID 를 엄격히 확인한 뒤엔 VLM 의 ID 재전사(`visible_mc_ids`/`row_confirmed`)를 게이트로 두지 않는다** — 대소문자/O·0 흔들림으로 정상 점유 행이 `unknown` 이 됐다(같은 사실에 게이트 둘은 더 안전하지 않고 약한 쪽의 잡음만 더한다). 산출물은 `debug_images/tool_occupancy/<ns>/`(list/row/cells.jpg, `connection_user_crop.webp`, `result.json` 의 `columns_px`/`connection_user_ocr` 원문/`diagnosis`). 테스트 `test_check_tool_occupancy.py` (9). 이 게이트가 오피스에서 확인되어 **`OK_CLICK=1`(완전 자동 제어)로 전환했다**(2026-09-15).
