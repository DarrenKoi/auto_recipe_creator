효율적 장비 운영을 위해 두 번째 MES 알람 — "측정 연속 실패" 자동 abort 잡을 프로덕션 루프에 추가했습니다. align fail(ALID=9006)만 처리하던 루프가, 정렬은 성공했으나 측정 포인트가 임계치(예: 100점 중 ~20점 연속 실패)를 넘기면 감지 → 접속 → 증거 캡처 → Stop/Abort 로 run 을 중단해 wafer 1장 손실을 막습니다. workflow_3 core 를 무수정으로 둔 채 확장 패키지 workflow_3e 로 구현했고, abort 클릭은 CV 보정과 동일한 이중 게이트 + notify-only 기본값으로 보호합니다(6 test 파일 통과). 병행으로 template-bank matcher 벤치를 7-task TDD 로 구현(오피스 평가 대기)했습니다.
